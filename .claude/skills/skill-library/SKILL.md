# Biblioteka skilli

1. Przy grze najpierw wywołaj `gamedev-router`. Wskaże skille po nazwie.
2. Przy aplikacji mobilnej otwórz `.claude/skill-library/INDEX.md` i wybierz 1–4 pasujące skille. Dla Expo zacznij od `expo-overview`.
3. Każdy wybrany skill przeczytaj z `.claude/skill-library/<nazwa>/SKILL.md` i stosuj tak, jakby był wywołany. Pliki z `references/` czytaj tylko w razie potrzeby.
4. Napisz użytkownikowi jednym zdaniem, których skilli używasz.
